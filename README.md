# Carta

An LLM-powered TUI for discovering and documenting feature requirements.

## Requirements

- Python 3.11+
- [OpenRouter](https://openrouter.ai/) API key

## Installation

```bash
python -m pip install -e .
```

## Usage

Set your API key:

```bash
export OPENROUTER_API_KEY="your-key-here"
```

Run the app:

```bash
carta
```

The TUI guides you through a discovery workflow:
1. Describe your feature
2. Answer clarifying questions generated by the LLM
3. Review the generated design document

## Development

Install with dev dependencies:

```bash
python -m pip install -e ".[dev]"
```

Run tests:

```bash
pytest
```

Watch mode:

```bash
ptw
```

Format and lint:

```bash
black src tests
ruff check src tests
```
